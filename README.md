# Notabene3

## How do I install these formulae?

`brew install md81544/notabene3/<formula>`

Or `brew tap md81544/notabene3` and then `brew install <formula>`.

Or, in a `brew bundle` `Brewfile`:

```ruby
tap "md81544/notabene3"
brew "<formula>"
```

## Documentation

`brew help`, `man brew` or check [Homebrew's documentation](https://docs.brew.sh).
